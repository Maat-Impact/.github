## 🌱 Quiénes somos

**Maat Impact** es la plataforma B2B SaaS que conecta empresas con **ONGs verificadas** para gestionar voluntariado corporativo de principio a fin: convocatorias, asistencia con QR, mentorización, gamificación y **reporting ESG / CSRD** listo para auditoría.

Hacemos que el impacto social deje de ser una hoja de Excel y se convierta en **dato accionable**.

<br/>

## ✨ Qué resolvemos

| | |
|---|---|
| 🤝 **Voluntariado corporativo** | Catálogo de ONGs verificadas, inscripciones, asistencia con QR, encuestas y certificados. |
| 📊 **Reporting ESG & CSRD** | Métricas de impacto auditables, exportables y alineadas con ESRS. |
| 🎯 **Engagement** | Gamificación, rankings, mentoría y comunicación interna integrada. |
| 🔐 **Compliance by design** | RBAC + MFA, cifrado AES-256-GCM, RPO < 1h, SSDLC con 19 controles en CI/CD. |
